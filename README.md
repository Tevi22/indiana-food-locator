# Indiana Food Locator

## Overview

Indiana Food Locator is a Java Spring Boot web application designed to help Indiana residents locate food assistance resources including food pantries, soup kitchens, mobile pantries, and SNAP offices.

## Features

- User Registration/Login
- Search by ZIP Code
- Search by City
- Google Maps Integration
- Favorites
- Admin Dashboard
- Responsive Design

## Technologies

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Bootstrap 5
- Maven
- Git
- GitHub
